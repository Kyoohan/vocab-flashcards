# 영단어 플래시카드

단어장 PDF를 올리면 단어를 자동으로 뽑아서, **영어 뜻풀이**를 보고 **예문 속 빈칸**에 단어를 채우는 문제로 외우는 웹 플래시카드입니다. 빌드 과정도 서버도 없이 정적 파일만으로 동작합니다. [코드 플래시카드](https://github.com/Kyoohan/code-flashcards)와 같은 디자인·채점 흐름으로 만들었습니다.

**🔗 바로 사용하기 → https://kyoohan.github.io/vocab-flashcards/**

## 주요 기능

- **PDF 자동 추출** — `단어 품사 한국어 뜻 — 영어 뜻` + `Example: 예문` 형식의 단어장(예: Nexus Vocabulary List)에서 단어 · 품사 · 한국어 뜻 · 영어 뜻 · 예문을 뽑습니다. 2단 편집, 줄바꿈된 뜻·예문, 페이지 머리말·꼬리말을 처리합니다. 여러 PDF를 한 번에 올려도 됩니다.
- **빈칸 위치** — 예문에서 **굵게** 표시된 단어가 빈칸이 됩니다(`accumulated`, `inventions`처럼 문장 속 형태 그대로). 굵은 표시가 없는 PDF는 표제어와 같은 단어(활용형 포함)를 찾아 빈칸으로 만들고, 못 찾으면 **단어 편집**에서 예문의 단어를 눌러 고릅니다.
- **핵심 단어** — PDF에서 파란색으로 표시된 표제어는 핵심 단어로 표시되고, 핵심 단어만 따로 출제할 수 있습니다.
- **문제** — 영어 뜻풀이(정답 단어가 뜻풀이에 들어 있으면 가립니다)와 빈칸 뚫린 예문. 한국어 뜻은 정답 후에 보여 주고, 옵션으로 문제에 함께 띄울 수 있습니다. 첫 글자 힌트, 발음 듣기(브라우저 음성)도 있습니다.
- **채점** — 틀리면 한 번 더 고칠 기회, 같은 답으로 다시 `Enter`하거나 비운 채 `Enter`하면 정답 공개(내 답 / 정답 비교), 채점이 억울하면 **정답으로 인정**(`⇧Enter`). 기본형(`accumulate`)을 쓰면 감점 없이 "문장에 맞는 형태로" 안내합니다.
- **라운드 · 세트** — 틀린 단어만 모아 다음 라운드에 다시 내고, 전부 맞힐 때까지 반복합니다. 한 세트 단어 수(10 · 20 · 30 · 50)를 정하면 세트 단위로 끊어서 외웁니다.
- **출제 범위** — 전체 / 핵심 / ★ 즐겨찾기 / 오답(한 번이라도 틀린 단어, 오답률 높은 순)
- **단어 목록** — 검색, 오답률 순 정렬, 즐겨찾기, 단어 편집·추가·삭제
- 라이트/다크 테마, 휴대폰 화면 지원

## 사용 방법

1. **단어장 PDF 올리기**를 누르거나 PDF를 화면에 끌어다 놓습니다.
2. 미리보기에서 뽑힌 단어와 빈칸 위치를 확인하고 **가져오기**를 누릅니다(새 단어장 또는 현재 단어장에 추가).
3. 영어 뜻을 보고 빈칸에 단어를 쓰고 `Enter`. 다 맞히면 `Enter`로 다음 단어로 넘어갑니다.

## 데이터 저장

단어·진행 상황·통계는 브라우저의 `localStorage`에 자동 저장되어 새로고침해도 풀던 자리에서 이어집니다. 브라우저·기기마다 따로 저장되므로, 다른 기기로 옮길 때는 **백업 내보내기 / 불러오기**(JSON)를 쓰세요.

PDF는 브라우저 안에서만 읽으며 어디에도 올리지 않습니다. 글자를 선택할 수 없는 스캔 PDF는 읽지 못합니다.

## 기술

빌드 도구가 없고, 라이브러리는 모두 `vendor/`에 내장되어 있습니다. 앱은 `index.html`과 PDF 단어 추출 모듈 `vocabpdf.js`로 이루어져 있습니다.

| | |
|---|---|
| [pdf.js](https://mozilla.github.io/pdf.js/) 3.11.174 | PDF 글자·서식(굵게·기울임·색) 추출. 처음 PDF를 올릴 때만 불러오며, CVE-2024-4367 대응으로 `isEvalSupported: false` |
| [jsdiff](https://github.com/kpdecker/jsdiff) | 오답 비교 |

## 로컬에서 실행

`index.html`을 브라우저로 열기만 하면 됩니다. 정적 서버로 띄우려면:

```bash
python3 -m http.server 8000
```
